Scope: the GitHub README of the private repo GUNNA-at/horizon-mod-translator (`.github/README.md`, with
`.github/README.ru.md` as its Russian twin). Mode: Read.

Audience and job: people the owner shows the project to (what it is, does it work, the numbers) and Horizon's
maintainers (architecture, boundaries, verification). Proof: the 43 pack runs, the in-game rounds, the tests.
Constraints: GitHub markdown only (no CSS, no JS); figures are SVG images in light and dark via `<picture>`,
generated by `tools/translator_progress.py` from `docs/translator/progress.json`.

## Direction contract

THESIS: A README with two doors. The opening answers "what is it and how far along" in one paragraph and one
line of numbers, then splits the reader by who they are: shown it, or working on Horizon. It refuses the
category's badge wall and feature grid.

OWN-WORLD: Horizon's world, inherited: the launcher's Night sky and dawn (banded sky, sliced sun, far hills) in
the masthead, Bricolage Grotesque Display for the name; Geist and Geist Mono, Horizon's ink, rules and one
violet for every figure, on GitHub's own ground.

STORY: The visitor learns it is a translator of any NeoForge mod into native Rust, sees that 91.6% of a real
pack's calls are answered and that Create runs in the game, then takes their door: try it, or read how it works
and how every number is checked.

FIRST VIEWPORT: Full-width masthead: the sky, the name at upper left, the subtitle, and a skyline built from
the pack's 367 jars (one column each, height by calls, checkered scaffold for what is unanswered). Below: the
language switch, the one-paragraph answer, the bold numbers line, then the two-door table, the reader's next
step.

FORM: Two doors (dealt lead, position 7 on the ranked list: pack ledger, measurement report, pipeline
walkthrough, datasheet, changelog, gaps-first, two doors). Seed key 0c5b0da9. Run unattended: the user was
away, so the dealt lead was built without the decision page.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
DESIGN.md, and every shipping raster carrying its provenance

Unresolved: the alternates (measurement report, pipeline walkthrough) stay open for a re-pick.
